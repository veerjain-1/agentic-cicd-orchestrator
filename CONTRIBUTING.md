# Contributing to Agentic CI/CD Orchestrator

First off, thank you for considering contributing to the Agentic CI/CD Orchestrator!

## Development Setup
1. Ensure you have Java 21+ installed.
2. Run `./gradlew build` to compile the engine.
3. We highly recommend using IntelliJ IDEA or Eclipse for development.

## Pull Request Process
1. Ensure your code compiles and passes tests before opening a PR.
2. Update the README.md with details of any architectural changes.
3. You may merge the Pull Request in once you have the sign-off of the maintainers.
